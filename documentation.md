# Документация по использованию калькулятора

## Основные функции

- **Сложение**: Нажмите на кнопку +, чтобы сложить два числа.
- **Вычитание**: Нажмите на кнопку -, чтобы вычесть одно число из другого.
- **Умножение**: Нажмите на кнопку x, чтобы умножить два числа.
- **Деление**: Нажмите на кнопку ÷, чтобы разделить одно число на другое.

## Специальные функции

- **C**: Сброс всех введённых данных.
- **⌫**: Удаление последнего введённого символа.
- **%**: Вычисление процента от числа.
- **log**: Вычисление десятичного логарифма числа.
- **|x|**: Вычисление модуля числа.
- **xʸ**: Возведение числа в степень.
- **x!**: Вычисление факториала числа.

## Темная и светлая темы

Вы можете переключаться между тёмной и светлой темами, нажав на иконку в правом верхнем углу экрана.
